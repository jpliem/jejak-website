# Jejak

3D-Printed Route Keepsakes — your running and cycling routes made tangible.

## What is Jejak?

Jejak ("trace" in Indonesian) turns GPS route data into beautifully crafted 3D-printed keepsakes. We make plaques, terrain maps, and keychains from your actual Strava or GPX routes.

## How to order

1. Contact us on WhatsApp
2. Send a GPX file or share your Strava profile
3. We design and send you a preview
4. You approve, we print
5. We deliver to your door

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

This is a static site deployed on Vercel. Push to `main` and it auto-deploys.

```bash
npm run build   # outputs to ./out
```
